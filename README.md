# 🛍️ ShopEase

A modern, fully-featured e-commerce store built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build step, no dependencies.

**🔗 Live demo:** https://YOUR_USERNAME.github.io/shopease/

## ✨ Features

- 🛒 **Shopping cart** with quantity controls, live totals & free-shipping progress bar
- ❤️ **Wishlist** with one-tap save & add-to-cart
- 📦 **Order history** stored locally, with printable receipts
- ⭐ **Product reviews** with verified-buyer lock
- 🏷️ **Sale badges**, **stock alerts**, and live **🔥 Trending** badges
- 🎟️ **Coupon codes** (SAVE10, SAVE20, WELCOME, FREESHIP)
- 🎁 **Gift wrap** option at checkout
- 🌙 **Dark mode** with saved preference
- 🔔 **Recently viewed** carousel
- 🖨️ **Printable receipts** & 🎉 **confetti** on order confirmed
- 📱 **Fully responsive** — works great on mobile

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, flexbox, animations, print styles
- **JavaScript (ES6+)** — vanilla, no libraries
- **localStorage** — persists cart, wishlist, orders, reviews, theme, recently viewed

## 🚀 Run Locally

Just open `index.html` in any modern browser. That's it.
